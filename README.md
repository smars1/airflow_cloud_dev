# Data Engineer Challenge

Este repositorio contiene la solucion propuesta para el challenge técnico de Data Engineer.  
La entrega se divide en dos secciones principales, de acuerdo con los requerimientos del ejercicio:

- `ejercicio1/`: implementacion practica del pipeline con Airflow, MinIO, Polars y Trino.
- `ejercicio2/`: documentacion de arquitectura, justificacion técnica y diagrama solicitado.
